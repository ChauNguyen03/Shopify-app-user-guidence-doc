# Gallery App User Guide — Reference & Log

## Naming conventions confirmed so far

| Term | Correct form |
|---|---|
| Lookbook | one word, no space |
| Custom image height | "Set the image height to match your design" (not "fixed height") |
| Hotspot tagging | "hotspot(s)" — plural when paired with "tags" |

## Pages written so far (for reference / consistency checks)

1. **Which gallery type should I use?** — comparison table (Gallery/Lookbook/Collage): Example, Best for, Layout options, Product tagging, Add to cart, Choose this if…
2. **How to set up gallery layout and image shape** — Layout style, Columns and spacing, Image appearance
3. **How to set up gallery heading and description** — Heading & Description (shared controls, set independently per field)
4. **How to set up hover image, text, button, link, and custom image height on image detail** — opened via hover+edit icon on image (Media source or preview)
5. **How to set up hotspot (tagging product) on image** — Add hotspot, Link, Reposition, Hotspot style, Tooltip style
6. **How to set up style for image, text, button, hotspot, tooltip, and carousel** (Global style) — Apply a style (in editor), Create/edit a style (Settings → Global presets)
