# Context: RockCats: PDF Catalog Maker

## 1. What is the app?
A Shopify app that turns store product data into branded catalogs, with no design skills needed.
- **Users:** Shopify merchants selling wholesale/B2B, and retailers who need lookbooks, line sheets or price lists.
- **Outputs:** PDF catalog (download or print) and flipbook catalog (shareable link).

## 2. Features

| Group | Features |
|---|---|
| Create | Start from a template (Classic catalog, Home decoration, Men's fashion) or blank; set page size, orientation, language and currency |
| Product pages | Pick products by list, collection or smart filter; set layout, card template, colors, header and footer |
| Canvas pages | Cover, Back and Custom pages with background and blocks: Text, Shape, Line, Image, Button, QR code, Product card |
| Table of contents | Auto-built from pages, sections and products; clickable page jumps |
| Products | Edit product details for the catalog only; refresh from store |
| Global settings | Logo, colors, typography, page margins, currency and language, wholesale pricing, price rounding, card templates, button styles, flipbook look and password |
| Publish | Export print-ready PDF (quality, crop marks, bleed); share, open or unpublish the flipbook |

## 3. How the app supports users

| User problem | How the app helps |
|---|---|
| Making catalogs in Canva or InDesign is slow | Builds pages from Shopify products and ready-made templates |
| Catalogs go out of date when prices change | Refresh product data from the store |
| Wholesale buyers need different prices | Wholesale pricing and price rounding in Global settings |
| Catalog doesn't look on-brand | Logo, colors and fonts set once for the whole catalog |
| Needs both print and online versions | One catalog exports as PDF and publishes as a flipbook |
| Catalog is private for some buyers | Password-protect the flipbook |
| Long catalogs are hard to browse | Table of contents with clickable page jumps |

## 4. Editor reference
- **Editor name in guides:** "Catalog editor".
- **General flow:** Dashboard > **Create new catalog** > choose template > page setup > design pages (**Add section**, **Add block**) > **Products** tab > Global settings > Export PDF or Share flipbook.
- **Fixed after creation:** catalog language and currency.
- **Shared settings:** Cover, Back and Custom pages use the same settings and blocks.
