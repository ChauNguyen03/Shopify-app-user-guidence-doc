# Gallery App User Guide — Page Template

## Page format (apply to every page)

1. **H1 title** — lists the features covered, e.g. "How to set up X, Y, and Z"
2. *Italic quick-index line* — short feature names only, comma-separated (not a sentence), e.g. `*Add hotspot, Link, Reposition, Hotspot style, Tooltip style*`
3. **Goal:** one sentence, what the merchant accomplishes on this page
4. **Where to see & edit [thing]:** how to open the relevant panel/modal in the editor
5. **What you can do in [thing]:** numbered list — each item = **bold feature name** + em dash (—) + short description (under ~10 words when possible)

## Writing rules

- Verb-first ("Set...", "Click...") — not "You can..."
- One idea per bullet
- Explain only what the name doesn't already say
- Bullets/tables over paragraphs for ≥3 options
- Image callouts = position only; body text = explanation
- No "?" on "How to..." titles
- Path: `gallery/how-to-use/gallery/[page-slug]` — lowercase, hyphens, no repeats
