# Gallery App User Guide — Writing Skill

**Goal:** Write short, easy-to-understand page content — a screenshot will be added later to support the text.

Use when writing/fixing a Gallery App user guide page.

1. Identify the feature area (Gallery, Lookbook, Collage, Global style) and find its matching link in `reference-and-log.md`.
2. Verify against the screenshot and that link — don't guess. Ask if unclear.
3. Check `reference-and-log.md` for existing naming and pages, stay consistent.
4. Write following `page-template.md` exactly.
5. Flag known open items instead of deciding silently.
6. After approval, remind Jolie to log the page and any new naming decision.

**Never:** invent fields/behavior, silently change the format, or copy competitor wording.
